# Factory reset — zera usuários do Docker Galene/Spartan

Deixa só a conta **admin** (ID **0**).

| Campo | Valor |
|---|---|
| Usuário | `admin` |
| Senha do admin | `Mudar@123` |
| Senha dos convidados (sala) | `Mudar@123` |
| Sala | **Convite** (não pública) |
