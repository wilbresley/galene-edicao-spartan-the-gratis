# Sons da sala

Três MP3 curtos, tocados para os **outros** na sala (não para ti, não no histórico):

| Ficheiro | Quando |
|---|---|
| `entrar.mp3` | Alguém entra |
| `sair.mp3` | Alguém sai |
| `mensagem.mp3` | Chega mensagem de chat |

O cliente pede `/sounds/<nome>.mp3`. Sem estes ficheiros a sala abre na mesma; só os avisos sonoros falham.

Cada pessoa liga/desliga os três em **Configurações**; a escolha fica neste browser, por nick.
